# baconmilkshake.com

Static landing page for baconmilkshake.com. Links to the project subdomains:

- meltcalc.baconmilkshake.com
- indx-cad.baconmilkshake.com
- toolchangers.baconmilkshake.com

Plain static files — no build step. Deploy the repo root as-is.

Note: the apex domain previously had a Cloudflare redirect rule sending
baconmilkshake.com -> meltcalc.baconmilkshake.com. That rule must be removed
for this page to be served.
